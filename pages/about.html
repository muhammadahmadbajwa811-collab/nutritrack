About NutriTrack

A calorie tracker that is simple enough to use every day and honest about what it does.

Why we built it

Most calorie apps ask for an account, a subscription and a lot of patience. We wanted a tracker that opens instantly, understands the food we actually eat, and does not send your data anywhere.

NutriTrack is a university project built with plain HTML, CSS and JavaScript. Everything you log is saved in your browser, so it works offline and stays private.

See the features

  • Local first

    Your meals, steps and weight live in your browser's storage. There is no server.

  • Food that looks like your plate

    The database includes everyday desi dishes next to the usual fruit, grains and snacks.

  • Honest numbers

    Values are approximate averages per serving, and the app says so.

  • Built to be portable

    The calculation code is separate from the interface so it can move into a mobile app later.

How it was built

Planned in a product requirements document, then built page by page.

  1. Plan

    Features, pages, data model and colour theme agreed in the PRD.

  2. Design

    One CSS file with shared tokens for colour, type and spacing, including dark mode.

  3. Build

    Small JavaScript modules for storage, calculations and each page.

  4. Test

    Checked on phone, tablet and desktop widths in both themes.
